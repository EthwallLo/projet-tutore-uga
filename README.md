# Découvrir le Japon

Projet de licence réalisé en groupe de six personnes. L’objectif est de créer un jeu de plateau sur navigateur pour découvrir la culture japonaise, inspiré de Wii Party et de GeoGuessr.

La première version propose une carte interactive du Japon. Un clic sur une ville ouvre une fiche avec une description et quelques repères culturels. Un mode nuit est également disponible.

Cette carte constitue la base du futur jeu, qui permettra aux joueurs d’explorer le Japon à travers des défis et des découvertes culturelles.
