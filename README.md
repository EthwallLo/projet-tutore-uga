# Découvrir le Japon

Projet de licence réalisé en groupe de six personnes. L’objectif est de créer un jeu de plateau sur navigateur pour découvrir la culture japonaise, inspiré de Wii Party et de GeoGuessr.

La version actuelle propose une carte illustrée du Japon. Un clic sur une ville ouvre une fiche avec une description et quelques repères culturels. Un mode nuit est également disponible.

Cette carte constitue la base du futur jeu. Les mécaniques seront ajoutées progressivement pour permettre aux joueurs de voyager, de collectionner des souvenirs et de découvrir la culture japonaise.
